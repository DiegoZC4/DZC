# Icon Assets

`homepage/` contains the final 72x72-ish icon-card SVGs that are used directly by `index.html`. If an icon is visible on the homepage, its final product should live there and its filename should match the page title or page slug.

`reference/` contains source marks, older variants, and non-final experiments. These files are useful for reconstruction, but they are not meant to be linked from the homepage.

Current LSRG files:

- `homepage/reading-group-backlog.svg` is the final homepage icon for `LSRG.html`.
- `reference/lsrg-discord-ratbook-source.svg` is the raw Discord-style rat/book SVG source used inside the final homepage icon.
- `reference/lsrg-ratbook-streamline-reference.svg` is an older non-final rat/book variant kept only as a reference.
