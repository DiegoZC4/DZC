Opus Bitrate Test

90 s of narration from Lord of Light ch. I, mono 48 kHz. Same source for every encode.

The source is already band-limited to 11.2 kHz — it is a YouTube audiobook rip, not a studio master. Every Opus encode at 16k and above reproduces that full bandwidth, so above 16k you are only buying back coding artifacts, not treble.

Container note

Each Opus row offers WebM first and Ogg second. Safari plays Opus in WebM but not in Ogg; Chrome and Firefox play both. If a row is silent in your browser, that row's container is unsupported — the codec is fine.

Encoder command

ffmpeg -i in.m4a -c:a libopus -b:a 24k -vbr on -compression_level 10 -application audio -ac 1 out.opus
