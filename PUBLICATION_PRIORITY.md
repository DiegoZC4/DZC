# Publication Priority

This is a ranked curation list for the website. It is meant to serve two jobs:

1. Decide what belongs on the homepage.
2. Identify which older or local projects are worth copying into the canonical `TODO.md` backlog.

The ranking favors finished interfaces, useful interactions, low deployment friction, and non-redundancy. When a better local version exists outside `public_html`, that version is ranked above the older copy already on the site. Selected external writing can appear on the homepage without being part of the local-file ranking.

Actionable follow-up items should live in `TODO.md`; this file is only for curation priority and publication context.
